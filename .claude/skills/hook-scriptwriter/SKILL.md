# Viral Hook & Scriptwriter Skill

## Rules
1. **Desire Hook First (0–3s):** Never open with "Hey guys", "Did you know", or vague curiosity bait. Open with a specific **Desired Outcome** + **Relatable Subject/Character** + **Timeframe or Proof**.
2. **Pacing:** Target 130–145 words per minute (~75–85 words for a 35s video). Short, punchy sentences. Max 12 words per line.
3. **Visual Rhythm:** Change the visual state every 2.5–4 seconds. Never leave a static talking head or static frame for more than 4 seconds.
4. **Re-Hook at 50%:** Insert a pattern-interrupt or stakes escalation halfway through the script so viewers don't drop off.

## Output Format
Always output in 3 sections:
1. **3 Desire Hook Variations** (Outcome-led, Contrarian/Mistake-led, Case-Study-led)
2. **Timed Script & Visual Beat Table** (`Timestamp` | `Spoken Line` | `On-Screen Text` | `Visual / Camera Action`)
3. **Loop Ending:** Write the final sentence so its cadence and meaning seamlessly flow back into Hook #1.
